## 一、模型迭代方案

前面的内容保留为背景和备选思路。最终建议把主方案收敛为“真实产率监督学习”，不再把候选档位优化器作为主链路。

说明：

lorderdata（下单量） 不适合作为最终监督学习目标本身，因为它确实是人工经验系数算出来的，模型直接学它，本质是在复制旧经验。旧经验如果偏保守、偏浪费、对低频组合不准，模型也会学进去。

但 lorderdata（下单量） 仍然必须参与训练标签构造。原因是：

真实产出 只有在某个历史下单量下发生。没有历史下单量，就没法判断这个产出是“下单多导致浪费”，还是“下单少但产出高”，也没法算：

真实产率 = (真实产出 / 下单) / (Lane拆分产出 / Lane下单)

所以结论是：

不学人工下单量本身；
用人工下单量作为历史实验条件；
用真实产出反推这个历史下单是否偏多或偏少；
学习修正后的目标，比如 real_rate（真实产率） 或 ideal_order_ratio（理想下单倍数）


### 1. 最终目标

线上主输出仍然只保留：

```
lorderdata（下单量）
```

`loutput（真实产出）` 只在历史训练和离线评估中使用，不在线上预测时作为输入，也不再做“预测下单量 -> 预测产出量 -> 再修正下单量”的链路。

最终方案名称：

```
基于 Lane 归一化真实产率的下单倍数模型
```

核心链路：

```
历史真实上机数据
    ↓
计算真实产率、理想下单量、理想下单倍数
    ↓
构造文库特征、Lane 特征、组合历史统计特征
    ↓
训练监督学习模型
    ↓
预测 ideal_order_ratio（理想下单倍数）
    ↓
final_lorderdata（最终下单量） = wkcontractdata（合同量） * ideal_order_ratio（理想下单倍数）
    ↓
业务上下限保护和低支持度回退
```

### 2. 训练标签

先按 Lane 汇总历史真实数据：

```
lane_output（Lane真实拆分产出） = sum（求和函数）(loutput（真实产出）)
lane_order（Lane真实下单总量） = sum（求和函数）(lorderdata（下单量）)
lane_efficiency（Lane平均效率） = lane_output（Lane真实拆分产出） / lane_order（Lane真实下单总量）
```

再对每个文库计算真实产率：

```
real_rate（真实产率） =
    (loutput（真实产出） / lorderdata（下单量）)
    /
    (lane_output（Lane真实拆分产出） / lane_order（Lane真实下单总量）)
```

这个 `real_rate（真实产率）` 是核心学习字段。它在线上不能直接得到，所以样本级 `real_rate（真实产率）` 是训练标签，不是线上输入特征。

由真实产率反推历史样本的理想下单量：

```
ideal_order（理想下单量） = lorderdata（下单量） * real_rate（真实产率）
ideal_order_ratio（理想下单倍数） = ideal_order（理想下单量） / wkcontractdata（合同量）
```

解释：

```
real_rate（真实产率） > 1：历史下单相对偏少，理想下单量应上调
real_rate（真实产率） < 1：历史下单相对偏多，理想下单量应下调
real_rate（真实产率） = 1：历史下单占比与真实产出占比匹配
```

最终模型建议直接学习 `ideal_order_ratio（理想下单倍数）`，或者学习 `log_ideal_order_ratio（理想下单倍数对数）`。其中 `real_rate（真实产率）` 同时作为解释字段和组合统计字段。

### 3. 特征字段

样本基础特征：

```
文库类型(wksampletype) --- 20%
      		文库建库环境(wkjkhj)：客户自建/诺禾手工/诺禾自动 -- 10%
      			库建综合结果(wkcomplexresult) --6% （合格/不合格/风险）
        			qpcr(wkqpcr) --- 13%
        			峰图(wkpeakmap) --- 6%
            				peaksize(wkpeaksize) --- 6%
            				小片段(wkxpd)  --- 6%
            				接头比值(wkqubit) --- 6%
    合同数据量(wkcontractdata)：22%
    是否碱基不均(wk_jjbj) --- 5%
```

Lane 特征：

```
Lane内文库数
Lane内合同量总和
Lane内文库类型数量
Lane内高风险文库占比
Lane内客户自建文库占比
当前文库合同量 / Lane合同量总和
```

组合历史统计特征：

```
real_rate_p25（真实产率第25百分位）
real_rate_p50（真实产率第50百分位）
real_rate_p75（真实产率第75百分位）
ideal_order_ratio_p25（理想下单倍数第25百分位）
ideal_order_ratio_p50（理想下单倍数第50百分位）
ideal_order_ratio_p75（理想下单倍数第75百分位）
observed_order_ratio_p50（历史实际下单倍数第50百分位）
support_count（支持样本数）
rate_std（真实产率标准差）
historical_shortage_rate（历史欠产率）
```

### 3.1 历史比例和CV特征使用

`合同/下单`、`合同/产出`、`产出/下单` 这三个比例需要统计历史数据，但不作为训练目标。它们更适合作为组合历史统计特征，帮助模型理解某类组合过去的人工下单经验、欠产风险和产出效率。

先在历史样本中计算三个基础比例：

```
contract_order_ratio（合同下单比） = wkcontractdata（合同量） / lorderdata（下单量）
contract_output_ratio（合同产出比） = wkcontractdata（合同量） / loutput（真实产出）
output_order_ratio（产出下单比） = loutput（真实产出） / lorderdata（下单量）
```

再按推荐历史层级 L6 到 L0 分组统计：

```
contract_order_ratio_p50（合同下单比第50百分位）
contract_order_ratio_cv（合同下单比变异系数）

contract_output_ratio_p50（合同产出比第50百分位）
contract_output_ratio_cv（合同产出比变异系数）

output_order_ratio_p50（产出下单比第50百分位）
output_order_ratio_cv（产出下单比变异系数）
```

其中：

```
CV（变异系数） = std（标准差函数） / mean（平均函数）
```

使用方式：

```
1. 训练集内，按时间窗口和推荐层级统计这些历史比例特征
2. 给每条训练样本拼接其所属组合在过去窗口中的统计值
3. 验证集、测试集和线上预测时，只能使用预测时间点之前的历史统计
4. 如果当前组合在 L6 样本数不足，则回退到 L5、L4、L3，直到样本数足够
5. 这些比例特征作为模型输入，训练目标仍然是 log_ideal_order_ratio（理想下单倍数对数）
```

第一版不建议把所有分位数都加入模型，避免特征过多。建议先使用 `P50（第50百分位） + CV（变异系数） + support_count（支持样本数）`。如果后续发现某些组合波动大，再补充 `P25（第25百分位）` 和 `P75（第75百分位）`。

注意：`contract_output_ratio（合同产出比）` 和 `output_order_ratio（产出下单比）` 都包含 `loutput（真实产出）`。它们只能来自历史统计，不能用当前待预测样本自己的真实产出计算，否则会造成数据泄漏。

组合统计特征必须只用训练窗口内的历史数据计算。验证集、测试集和线上预测不能使用未来数据，否则会产生数据泄漏。

### 4. 历史统计层级是否有必要

有必要，而且这是关键特征。

模型不可能凭单条样本把所有高维组合学准。历史统计层级的作用是把“这个组合过去真实产率怎样、波动多大、样本数够不够”显式告诉模型。

推荐层级：

```
L6 = wksampletype（文库类型） + wkjkhj（文库建库环境） + wkcomplexresult（库建综合结果） + wkqpcr（QPCR定量检测） + wkpeakmap（峰图） + wkpeaksize（峰图主峰片段大小） + wkxpd（小片段） + wkqubit（接头比值） + contract_bin（合同数据量分箱） + wk_jjbj（是否碱基不均）
L5 = wksampletype（文库类型） + wkjkhj（文库建库环境） + wkcomplexresult（库建综合结果） + wkqpcr（QPCR定量检测） + wkpeakmap（峰图） + wkpeaksize（峰图主峰片段大小） + wkxpd（小片段） + wkqubit（接头比值）
L4 = wksampletype（文库类型） + wkjkhj（文库建库环境） + wkcomplexresult（库建综合结果） + wkqpcr（QPCR定量检测） + wkpeakmap（峰图）
L3 = wksampletype（文库类型） + wkjkhj（文库建库环境） + wkcomplexresult（库建综合结果）
L2 = wksampletype（文库类型） + wkjkhj（文库建库环境）
L1 = wksampletype（文库类型）
L0 = 全局
```



### 5. 模型选择

首选：

```
CatBoostRegressor（类别提升回归模型）
```

原因：

- 类别字段多；
- 组合特征多；
- 低频类别需要平滑；
- 不需要把类别强行做 `LabelEncoder（标签编码器）` 顺序编码；
- 比现有 XGBoost（极端梯度提升模型） 更适合这类高维类别组合。

对照模型：

```
XGBoost（极端梯度提升模型）作为baseline基线模型
```

第一版不要做复杂模型融合。先用一个主模型 + 历史统计回退，把目标定义和评估口径跑通。

### 6. 训练目标

```
target（训练目标） = log_ideal_order_ratio（理想下单倍数对数）
log_ideal_order_ratio（理想下单倍数对数） = log（对数函数）(ideal_order_ratio（理想下单倍数）)
```

使用对数目标有两个好处：

- 上调和下调更对称；
- 极端大值对模型影响更小。

预测后还原：

```
pred_ideal_order_ratio（预测理想下单倍数） = exp（指数函数）(model_output（模型输出）)
pred_lorderdata（预测下单量） = wkcontractdata（合同量） * pred_ideal_order_ratio（预测理想下单倍数）
```

### 7. 数据处理

数据范围和数据集划分：

```
当前已整理的 2025 年至 2026 年 2 月数据总量为 614,860 条。
后续会继续补充 2024 年历史数据，补充后重新生成完整模型训练数据。
模型训练集、验证集、测试集按 8:1:1 分配。
```

按当前 614,860 条数据计算：

```
训练集约 491,888 条
验证集约 61,486 条
测试集约 61,486 条
```

实际训练时应以清洗、去重、异常标记后的可用样本数重新计算 8:1:1 划分。涉及历史统计特征时，验证集、测试集不能使用未来时间窗口的数据，避免数据泄漏。

必须保留真实好结果和真实坏结果。不能因为产出差就删除，否则模型学不到哪些组合真实产率偏离 1。

需要剔除或单独标记的数据：

```
合同量为空或小于等于 0
下单量为空或小于等于 0
真实产出为空或明显不可信
Lane归属缺失或明显错误
单位错误
重复记录
机器故障、补测、污染、人工异常调整等异常场景
```

异常场景不要一律删除。能解释的异常应打标；无法解释且明显不属于正常生产规律的样本再剔除。

标签截尾建议：

```
real_rate（真实产率） 按 P1（第1百分位） 到 P99（第99百分位） 截尾
ideal_order_ratio（理想下单倍数） 按 P1（第1百分位） 到 P99（第99百分位） 截尾
```

### 8. 线上预测

```
输入当前文库和 Lane 特征
读取当前组合的历史统计特征
CatBoostRegressor（类别提升回归模型） 输出 pred_ideal_order_ratio（预测理想下单倍数）
计算 pred_lorderdata（预测下单量）
按业务上下限裁剪
低支持度组合回退到父层级统计下单倍数
输出 final_lorderdata（最终下单量）
```

业务保护：

```
final_lorderdata（最终下单量）不能小于业务最低下单量
final_lorderdata（最终下单量）不能大于历史同组合合理上限
低支持度或新组合降低模型权重，优先使用父层级统计值
```



## 二、评估方案

评估方案改为使用真实历史上机数据验证，不再使用“预测下单量 -> 预测产出量 -> 计算欠产率/浪费率”的链路。

核心思想：

```
用真实产出不变
把历史真实下单替换成模型预测下单
计算 Lane 归一化后的真实产率变化
```

### 1. 核心公式

（真实产出/下单）/（lane拆分产出/lane下单）=真实产率

对每个文库 `i`，属于 Lane `g`：

```
真实产出 = real_output_i（第i个文库真实产出）
预测下单 = pred_order_i（第i个文库预测下单量）
真实Lane拆分产出 = real_lane_output_g（第g个Lane真实拆分产出）
Lane预测下单 = pred_lane_order_g（第g个Lane预测下单总量）
```

其中：

```
pred_lane_order_g（第g个Lane预测下单总量） = sum（求和函数）(pred_order_i（第i个文库预测下单量） for i in lane g)
```

按预测下单替换后的真实产率定义为：

```
pred_replaced_real_rate_i（第i个文库预测下单替换后的真实产率） =
    (真实产出 / 预测下单)
    /
    (真实Lane拆分产出 / Lane预测下单)
```

也就是：

```
pred_replaced_real_rate_i（第i个文库预测下单替换后的真实产率） =
    (real_output_i（第i个文库真实产出） / pred_order_i（第i个文库预测下单量）)
    /
    (real_lane_output_g（第g个Lane真实拆分产出） / pred_lane_order_g（第g个Lane预测下单总量）)
```

等价理解：

```
pred_replaced_real_rate_i（第i个文库预测下单替换后的真实产率） =
    文库真实产出占比 / 文库预测下单占比
```

即：

```
pred_replaced_real_rate_i（第i个文库预测下单替换后的真实产率） =
    (real_output_i（第i个文库真实产出） / real_lane_output_g（第g个Lane真实拆分产出）)
    /
    (pred_order_i（第i个文库预测下单量） / pred_lane_order_g（第g个Lane预测下单总量）)
```

这个指标表示：在真实 Lane 产出已知的情况下，如果把下单量替换成模型预测下单量，该文库相对 Lane 平均水平的真实产率是多少。

理想值是：

```
pred_replaced_real_rate_i（第i个文库预测下单替换后的真实产率） = 1
```

### 2. 历史真实产率基准

为了判断模型是否优于历史下单，需要同时计算历史真实下单口径下的真实产率。

历史字段：

```
历史真实下单 = historical_order_i（第i个文库历史真实下单量）
Lane历史真实下单 = historical_lane_order_g（第g个Lane历史真实下单总量）
```

其中：

```
historical_lane_order_g（第g个Lane历史真实下单总量） = sum（求和函数）(historical_order_i（第i个文库历史真实下单量） for i in lane g)
```

历史真实产率：

```
historical_real_rate_i（第i个文库历史真实产率） =
    (真实产出 / 历史真实下单)
    /
    (真实Lane拆分产出 / Lane历史真实下单)
```

即：

```
historical_real_rate_i（第i个文库历史真实产率） =
    (real_output_i（第i个文库真实产出） / historical_order_i（第i个文库历史真实下单量）)
    /
    (real_lane_output_g（第g个Lane真实拆分产出） / historical_lane_order_g（第g个Lane历史真实下单总量）)
```

### 3. 模型达标判断

按该评估口径，核心判断不是 `pred_replaced_real_rate_i（第i个文库预测下单替换后的真实产率）` 越大越好，而是离 1 越近越好。

```
pred_rate_error_i（第i个文库预测真实产率误差） = abs（绝对值函数）(pred_replaced_real_rate_i（第i个文库预测下单替换后的真实产率） - 1)
historical_rate_error_i（第i个文库历史真实产率误差） = abs（绝对值函数）(historical_real_rate_i（第i个文库历史真实产率） - 1)
```

如果满足：

```
pred_rate_error_i（第i个文库预测真实产率误差） <= historical_rate_error_i（第i个文库历史真实产率误差）
```

说明在真实历史产出不变的前提下，把历史下单替换成预测下单后，该文库的 Lane 归一化真实产率更接近 1，模型达到该样本的目标要求。

样本级结果：

```
rate_pass_i（第i个文库真实产率通过标记） = pred_rate_error_i（第i个文库预测真实产率误差） <= historical_rate_error_i（第i个文库历史真实产率误差）
```

差值：

```
rate_error_delta_i（第i个文库真实产率误差差值） = pred_rate_error_i（第i个文库预测真实产率误差） - historical_rate_error_i（第i个文库历史真实产率误差）
```

其中：

```
rate_error_delta_i（第i个文库真实产率误差差值） < 0：预测下单更接近理想真实产率 1
rate_error_delta_i（第i个文库真实产率误差差值） = 0：与历史下单持平
rate_error_delta_i（第i个文库真实产率误差差值） > 0：预测下单比历史下单更偏离 1
```

### 4. 必须同时保留的保护条件

该指标不能单独使用。因为如果模型把 `pred_order_i（第i个文库预测下单量）` 压得过低，`real_output_i（第i个文库真实产出） / pred_order_i（第i个文库预测下单量）` 会变大，可能导致产率指标虚高。

因此样本达标必须同时满足：

```
pred_rate_error_i（第i个文库预测真实产率误差） <= historical_rate_error_i（第i个文库历史真实产率误差）
pred_order_i（第i个文库预测下单量） >= min_order_i（第i个文库最低下单量）
pred_order_i（第i个文库预测下单量） <= max_order_i（第i个文库最高下单量）
pred_order_i（第i个文库预测下单量） 不明显远离历史同组合可观测范围
```

其中：

```
min_order_i（第i个文库最低下单量） = 业务允许的最低下单量
max_order_i（第i个文库最高下单量） = 业务允许的最高下单量
```

最终样本通过条件：

```
sample_pass_i（第i个样本通过标记） =
    rate_pass_i（第i个文库真实产率通过标记）
    and order_lower_bound_pass_i（第i个文库下限通过标记）
    and order_upper_bound_pass_i（第i个文库上限通过标记）
    and in_support_range_i（第i个文库在历史支持范围内标记）
```

### 5. Lane 级评估

每个 Lane 需要汇总：

```
pred_lane_order_g（第g个Lane预测下单总量） = sum（求和函数）(pred_order_i（第i个文库预测下单量）)
historical_lane_order_g（第g个Lane历史真实下单总量） = sum（求和函数）(historical_order_i（第i个文库历史真实下单量）)
real_lane_output_g（第g个Lane真实拆分产出） = sum（求和函数）(real_output_i（第i个文库真实产出）) 或真实Lane拆分产出
```

Lane 级评估不再额外引入下单变化比例、P95（第95百分位） 或多套误差指标。仍然只看同一个真实产率目标：该 Lane 内文库在预测下单替换后，真实产率是否更接近 1。

```
lane_real_rate_better_ratio_g（第g个Lane真实产率更优比例） =
    mean（平均函数）(real_rate_better_i（第i个文库真实产率更优标记） for i in Lane g)
```

### 6. 汇总指标

整体评估只围绕真实产率，不再同时输出多套误差指标。核心就是比较“历史下单下的真实产率”和“预测下单替换后的真实产率”谁更接近 1。

```
historical_real_rate_i（第i个文库历史真实产率）
pred_replaced_real_rate_i（第i个文库预测下单替换后的真实产率）
```

真实产率偏离 1 的距离：

```
historical_real_rate_gap_i（第i个文库历史真实产率偏离） =
    abs（绝对值函数）(historical_real_rate_i（第i个文库历史真实产率） - 1)

pred_real_rate_gap_i（第i个文库预测替换真实产率偏离） =
    abs（绝对值函数）(pred_replaced_real_rate_i（第i个文库预测下单替换后的真实产率） - 1)
```

单个文库是否变好：

```
real_rate_better_i（第i个文库真实产率更优标记） =
    pred_real_rate_gap_i（第i个文库预测替换真实产率偏离）
    <= historical_real_rate_gap_i（第i个文库历史真实产率偏离）
```

整体只汇总一个主指标：

```
real_rate_better_ratio（真实产率更优比例） =
    mean（平均函数）(real_rate_better_i（第i个文库真实产率更优标记）)
```

分层评估也只看同一个指标 `real_rate_better_ratio（真实产率更优比例）`，不再新增其他指标：

```
按 wksampletype（文库类型） 分组
按 wkjkhj（文库建库环境） 分组
按 wkcomplexresult（库建综合结果） 分组
按 wkqpcr（QPCR定量检测） 分组
按 wkpeakmap（峰图） 分组
按 wkpeaksize（峰图主峰片段大小） 分组
按 wkxpd（小片段） 分组
按 wkqubit（接头比值） 分组
按 contract_bin（合同数据量分箱） 分组
按 wk_jjbj（是否碱基不均） 分组
按 Lane 分组
按高频 / 中频 / 低频 / 新组合分组
```

### 7. 通过标准

建议通过标准：

```
real_rate_better_ratio（真实产率更优比例） 达到业务设定阈值
各关键分层的 real_rate_better_ratio（真实产率更优比例） 不明显低于整体
预测下单替换后的真实产率整体更接近 1
低频组合和新组合不能出现大面积真实产率远离 1
```

下单上下限、历史合理范围和异常样本过滤属于业务保护条件，仍然要保留，但不作为本节的主评估指标。主评估指标只看真实产率是否更接近 1。
